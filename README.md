# Monorepo

Multi-language Bazel monorepo template supporting Go and Python projects.

## Prerequisites

Install [Bazelisk](https://github.com/bazelbuild/bazelisk) (a version manager for Bazel):

```bash
npm install -g @bazel/bazelisk
```

## Getting Started

Start the development shell:

```bash
./devshell.sh
```

### What devshell.sh Does

The `devshell.sh` script creates an isolated development environment with Bazel-managed tools:

1. **Builds hermetic tools** - Downloads and builds exact versions of Go, Python, protoc, buildifier, and shfmt via Bazel
2. **Creates tool wrappers** - Generates wrapper scripts in `bin/` that point to the Bazel-built binaries
3. **Sets up Python venv** - Creates a virtual environment with dependencies from `requirements.txt`
4. **Launches a configured shell** - Starts a new shell with:
   - Tools available in PATH (`go`, `python3`, `protoc`, `buildifier`, `shfmt`)
   - Custom prompt showing `[devshell]` to indicate you're in the environment
   - Proper GOPATH, PYTHONPATH, and other environment variables set

The environment is isolated and cannot be nested. To exit, type `exit` or press `Ctrl+D`.

## Building and Running

This repository uses [Bazel](https://bazel.build/) as its build system.

### Building Projects

```bash
# Build a specific target
bazel build //path/to/target

# Build everything
bazel build //...

# Run a target
bazel run //path/to/target
```

Example - run the Go hello world:

```bash
bazel run //src/go/helloworld
```

### Formatting Code

Format all code in the repository:

```bash
bazel run //:format
```

Or format specific languages:

```bash
bazel run //:format-shell      # Shell scripts (shfmt)
bazel run //:format-go         # Go files (gofmt)
bazel run //:format-buildifier # Bazel files (buildifier)
```

### Updating BUILD Files

We use [Gazelle](https://github.com/bazelbuild/bazel-gazelle) to automatically manage Bazel BUILD files. After adding or modifying Go/Python code:

```bash
bazel run //:gazelle
```

### Managing Python Dependencies

To add new Python dependencies:

1. Add them to `requirements.txt`
2. Update the lock file:
   ```bash
   bazel run //:requirements.update
   ```
3. Update BUILD files:
   ```bash
   bazel run //:gazelle
   ```

## Project Structure

```
.
├── bin/              # Tool wrappers (generated by devshell.sh)
├── tools/            # Bazel tool definitions and format scripts
├── src/
│   ├── go/           # Go source code
│   │   └── helloworld/
│   └── python/       # Python source code
│       └── helloworld/
├── devshell.sh       # Development environment setup script
├── BUILD.bazel       # Root Bazel build file
├── MODULE.bazel      # Bazel module dependencies
└── .editorconfig     # Editor formatting configuration
```
